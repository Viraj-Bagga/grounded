B. RAM AND TIMING ON THE SERVER PATH, measured on the running demo server.

   demo server RSS before any transcription   486 MB
   whisper-cli peak RSS during three runs     265 MB
   demo server RSS after                      276 MB

   The server does not grow, because transcription is a subprocess that exits.
   The 486 to 276 drop is the OS reclaiming pages, not a leak.

   6.18 s of speech  ->  528 ms      (warm)
   25.0 s of speech  ->  829 ms      (warm)
   6.18 s of speech  ->  455 ms      (warm)
   6.18 s of speech  ->  969 ms      (cold, first run after boot)
   25.0 s of speech  ->  1598 ms     (cold)

   Wall time has a floor of about 0.5 s and grows slowly with length, because
   whisper always encodes a fixed 30 s window. Model load inside that is 46 ms,
   which is why the model is not held resident.

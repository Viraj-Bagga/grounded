1. THE STAGING DIRECTORY, and why the merge was not converted in place
================================================================================
transformers 5.17 wrote metadata beside the merge that is NOT what section 3 was
proven with:

  * merged config.json has NO hybrid_override_pattern. It has 5.x's
    layers_block_type, plus a block of MoE defaults (n_routed_experts,
    moe_intermediate_size, mtp_layers_block_type) that do not apply to this
    model. The current converter reads either key, checked in
    conversion/nemotron.py lines 243 and 274, so this would probably have
    worked. It was not used anyway.
  * merged tokenizer_config.json is 364 bytes: 5.x's minimal TokenizersBackend
    form, no added_tokens_decoder, no add_bos_token, no chat template. The base
    one is 188 KB and carries all of it.
  * merged has no special_tokens_map.json.

So 03-model/convert-src-120pairs/ holds a symlink to the merged weights and
copies of NVIDIA's own metadata from 03-model/hf-bf16. Checked first, so this is
a substitution and not a hope:

  tokenizer.json is BYTE-IDENTICAL in both, sha 623c34567aebb185.
  merged/chat_template.jinja vs the template embedded in the base
    tokenizer_config.json: 26 diff lines, every one a blank line 5.x inserted.
    No template logic differs.

LoRA merging changes weights, not architecture or vocabulary. The point is that
the only thing separating this conversion from the proven 2026-09-18 one is the
weights.

WHAT THIS PROVES, AND WHAT IT DOES NOT
================================================================================
PROVES: the fine-tuned model survives the same conversion chain the base does,
loads under llama-server on CPU, honours the reasoning switch, and stops.

DOES NOT PROVE: anything about the verdicts. Loading is not proof; the corrupt
q8_0 loaded too. Runbook section 7's acceptance test is a SAMENESS test and is
the wrong test here, because the whole point of the adapter is that the verdicts
should move. The right test is the frozen 22-case held-out set, base against
tuned, which is step 6 and has not been run at the time of writing.

ALSO NOT MEASURED: tok/s on this artifact. Low Power Mode was on for everything
above, so no latency number here belongs in the demo notes.

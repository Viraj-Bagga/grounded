# Sub-Saharan Africa add-on: tuberculosis and sickle cell acute chest syndrome

EXPERIMENTAL add-on pack. An OVERLAY on `corpus-base`, never a swap:
selecting this region gives the base corpus plus this pack. Requires `corpus-base`.

**Not wired into retrieval.** The demo shows which pack is active and what it
holds; retrieval still uses the base corpus alone. Viraj's call, 2026-09-19.

## Emergency number

none, use local emergency services. There is no single emergency number across this region, so the pack names none and says "local emergency services". Base chunks that say 9-1-1 are shown as they are, annotated, never edited or suppressed.
